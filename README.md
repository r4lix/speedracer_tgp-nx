# Speed Racer: The Great Plan - Nintendo Switch

Native Nintendo Switch port of the 2005 PC game Speed Racer: The Great Plan
(Iron Monkey / Blit Interactive). Race the Mach 5 from the starting grid to the finish line.

## Install
1. Download the game from the Releases page.
2. Copy the nro to your switch folder on your SD card.
3. Start it from the Homebrew Menu (with full memory).

## Controls
| Button | Action |
|---|---|
| ZR / ZL | drive / brake |
| Left stick or D-pad | steer |
| A | jacks (jump) |
| B | belt tires |
| Y | cutter blades |
| R | homing robot |
| D-pad up / down | lights / frogger mode |
| Minus | deflector |
| L3 | show/hide help |
| Plus | back / quit |

Hold Minus for 1.5 seconds to open the Super Secret Menu: change the buttons, HUD layout,
cheats and more. The touch screen works on the menu pages.
